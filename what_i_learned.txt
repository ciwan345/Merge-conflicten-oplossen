What I learned – Git Workshops 
Ik heb geleerd hoe ik mijn eigen branch kan gebruiken, zodat ik apart van mijn klasgenoot aan mijn bestanden kan werken.
Ik heb onder andere deze commando's gebruikt:
git branch
git switch Mohamed-branch
git branch -a 
Ik heb hiermee mijn branches bekeken en naar mijn eigen branch gewisseld.

ik heb hiervoor Git Bash gebruikt met het commando:
git clone https://github.com/gebruikersnaam/repository.git
Hierdoor kon ik lokaal met de bestanden van de repository werken. 
Wat ik heb geleerd tijdens de afgelopen 3 Git-opdrachten:

1. Ik heb geleerd hoe ik een Git-repository aanmaak.
2. Ik heb geleerd hoe ik `git add` en `git commit` gebruik.
3. Ik heb geleerd hoe ik branches aanmaak en ertussen wissel.
4. Ik heb geleerd hoe ik wijzigingen naar GitHub push en ervan ophaal (pull).

Wat ik nog wil leren:

1. Hoe ik merge-conflicten oplos.
2. Hoe ik `git rebase` gebruik.
3. Hoe ik met pull requests werk.
